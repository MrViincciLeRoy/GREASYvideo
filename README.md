# GREASYvideo
## Introduction
GREASYvideo is a project designed to analyze comic books and track characters. It features API key rotation and character tracking.
## Key Features
- API key rotation for enhanced API usage
- Character tracking and analysis
- Support for various comic book formats
## Tech Stack
- Python 3.x
- Playwright
- Pytesseract
- OpenCV
- NumPy
- Pillow
## Installation
To install the project, run `pip install -r requirements.txt`.
## Usage
To use the project, run `python greasy/scraper.py`.
## Environment Variables
The following environment variables are required:
- `API_KEY`: the API key for the comic book API
- `COMIC_FORMAT`: the format of the comic book (e.g. "auto", "traditional", "webtoon")
